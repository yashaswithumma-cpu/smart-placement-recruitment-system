# Smart Placement & Recruitment Management System

A full-stack web application designed to simplify college placement activities by connecting students, recruiters, and placement officers through a centralized platform.

## 🌐 Live Demo

**Live Website:** https://smart-placement-recruitment-system.vercel.app

## ✨ Features

* Student login and authentication
* Student dashboard
* Student management
* Recruiter management
* Job and placement drive management
* Placement application tracking
* Database integration for storing application data

## 🛠️ Technologies Used

**Frontend**

* React.js
* Vite
* JavaScript
* CSS

**Backend**

* Java
* Spring Boot
* REST APIs
* Maven

**Database**

* MySQL

**Deployment**

* Vercel — Frontend
* Render — Backend
* Railway — Database

## 🏗️ System Architecture

React Frontend → Spring Boot REST API → MySQL Database

## 🚀 Running the Project Locally

### Prerequisites

* Java Development Kit (JDK)
* Maven
* Node.js and npm
* MySQL

### Frontend Setup

1. Open the frontend folder in the terminal.

2. Install dependencies:

   `npm install`

3. Configure the backend API URL in your environment file.

4. Start the development server:

   `npm run dev`

### Backend Setup

1. Configure the MySQL database connection using your local environment variables.
2. Run the Spring Boot application using your IDE or Maven.
